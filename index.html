About Me

I'm a final-year Computer Science student at Isabela State University, Echague, Isabela, pursuing a specialization in Data Mining. My work lives at the intersection of machine learning, computer vision, and practical web engineering.

My capstone project, FishCount, is an AI-powered fish stock estimation system co-developed with Jaztine D. Maltizo. It uses a custom-trained SSD-MobileNetV2 model with FPN-Lite feature fusion and 22 K-Means anchor boxes — deployed entirely in the browser via ONNX Runtime Web, requiring no cloud GPU infrastructure.

Beyond the thesis, I enjoy building full-stack systems with clean architecture: RESTful Python backends, normalized relational databases, and responsive UIs. I'm actively seeking an OJT / internship opportunity to bring these skills to a professional team.
